# A 股日线策略选股

入口：侧栏「策略选股」。选择策略与股票池，保存并应用后生成候选；「历史回测」使用同一份已保存参数。该模块在本地研究并保存结果，不发送证券订单。

## 问财 / 妙想平台选股

页面顶部「平台智能选股」可切换同花顺 i 问财和东方财富妙想，两家各自保存 API Key 与自然语言查询条件。选择平台后填写密钥、查询条件和数量，点击「查询候选股」。每次点击会调用当前平台并使用其额度，当前版本不自动轮询付费平台；下方本地日线策略仍按原规则自动更新。

- **问财**：前往 [官方 SkillHub](https://www.iwencai.com/skillhub)，登录并打开任一官方 Skill，在「安装方式 / Agent 用户」取得 `IWENCAI_API_KEY`。填写 SkillHub 密钥，不是网页 Cookie 或 iFind access token。使用官方 A 股选股接口 `https://openapi.iwencai.com/v1/query2data`，请求和字段参考 [官方技能包](https://ms.10jqka.com.cn/gateway/market/api/v1/skills/square/download?name=hithink-astock-selector)。单次请求第一页，最多 60 条；页面显示平台总匹配数和截断提示，不把当前页称为全部结果。
- **妙想**：前往 [妙想技能·MCP](https://ai.eastmoney.com/skills) 的「查看 API Key」取得密钥，需要智能选股权限和可用额度。使用 [官方 MCP](https://mxapi.eastmoney.com/mxds/doc/mcp-install.md) 的 Streamable HTTP 服务 `https://mxapi.eastmoney.com/mxds/mcp` 和 `em_api_key` 请求头。运行时初始化、读取工具参数定义，再调用唯一匹配的智能选股工具；工具不明确、参数不兼容或缺权限时明确报错，不尝试交易或账户操作。
- 平台结果保留股票代码、名称、原始指标标签（含日期）与返回说明。只解析明确的股票表格，不从模型叙述中猜股票代码；不支持的市场和代码排除并提示。查询时间不等于行情日期，请核对返回字段上的日期。
- 勾选候选后点击「应用到策略股票池」，会保存为自定义股票池，带上平台、条件和查询时间。下方可继续进行技术策略筛选与固定池回测。**当前名单的历史回测包含前视偏差，不能代表该自然语言条件在历史各日的选股收益。** 编辑股票代码或换成本地其他股票池后移除原名单来源标记。
- 保存最近 30 次平台查询。配置和结果位于应用数据目录 `stock-selection/state-v1.json`。密钥单独写入 `keys-v1.json`，使用 Electron `safeStorage` 加密；安全存储不可用时拒绝明文回退，状态接口仅返回是否已配置。密钥不进入渲染进程返回值、源码或结果历史；更换机器后可能需要重新填写。

接入测试：`npx vitest run tests/ai-selection.test.ts tests/stock-strategy.test.ts tests/service-schemas.test.ts`。覆盖两家鉴权隔离、MCP 初始化与 SSE、代码和指标解析、权限失败、重复请求、加密存储及导入来源校验。接口测试使用响应样例，尚未使用用户 API Key 做线上授权联调。隔离页面的浏览器检查被客户端拦截（`ERR_BLOCKED_BY_CLIENT`），未验证实际渲染和完整 Electron 操作流程。

## 当前范围

- 趋势动量、放量突破、趋势回踩；每种策略的条件和排名公式在页面中公开。
- 本地日线扫描支持沪深 A 股：我的自选、现有内置观察池、自定义代码（含平台结果导入）。单次最多 60 只，未接入全市场本地扫描或历史指数成分库。
- 腾讯原始与前复权日线分别下载，必须按日期对齐；不以未复权行情替代复权行情。取沪深 300 日线作为交易日序列及价格指数基准。
- 当日 15:30 前只使用前一自然日及以前的数据，再由实际指数行情确定信号日；盘中不使用未完成日线。候选用于下一实际交易日，不按周一至周五推测节假日。
- 打开每日候选页后每分钟检查，结果与行情缓存 15 分钟；可手动刷新。应用关闭、页面离开或处于后台时不会持续扫描。
- 保存最近 30 份筛选结果及最近一次成功回测。设置和结果保存在应用数据目录 `stock-strategy/state-v1.json`，原子替换，不写持仓或交易流水。

## 回测口径

支持 2023-08-28 之后、最长两年的区间，需要每只股票额外 61 根预热日线。公开接口单次最多取 640 根，数据不足时提示缩短区间。某只股票下载失败会中止回测，不通过删除失败标的继续计算。

前一交易日收盘产生信号，下一交易日开盘买入。最多持有 Top N 只，按当前组合权益的 1/N 分配新仓预算，不足部分留现金，不每天强制再平衡。达到持有期限、收盘跌破 20 日均线或触发止盈止损时，下一交易日开盘卖出；停牌及近似跌停会继续保留卖出意图，当日卖出的股票不立即买回。

买入按原始价格和可用资金计算数量：一般股票 100 股整数倍，科创板至少 200 股、之后按 1 股递增。内部以复权等效单位估值与平仓，费用按模拟成交额计算，现金以分取整。**这是复权资金研究模型，不是逐笔还原公司行动的实盘账本**；等效卖出股数可能含碎股。期末未平仓部分按最近可用收盘估值，不虚构末日平仓成交。区间不足 30 天不显示年化，无平仓交易不显示胜率。

页面展示固定股票池的幸存者偏差、分红复权近似、历史 ST 状态缺失、涨跌停近似、交易容量未建模等限制。沪深 300 是价格指数，不含分红，不能把策略与基准之差直接理解为风险调整后的超额收益。费用参数在全区间固定，用户应按自己的研究口径调整。

规则参考：[上交所科创板投教](https://edu.sse.com.cn/tib/qa/)、[深交所创业板交易规定](https://investor.szse.cn/institute/rules/t20200813_580574.html)、[证券交易印花税减半公告](https://shanghai.chinatax.gov.cn/gate/big5/shanghai.chinatax.gov.cn/tax/zcfw/zcfgk/yhs/202308/t468451.html)。
