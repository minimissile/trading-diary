## 已完成

- 工作区采用石墨、青碧和暖金主题；清理旧玻璃层中的蓝紫配色、渐变面板和悬浮位移。

- 规则激活清单显示加载失败和重试入口；失败或未完成核对时禁止提交。
- 修复盈亏日历同步请求校验遗漏、定投汇总类型、拆分文件导入路径及相关协议默认值。

- 全局 Yingji UI Skill 与组件规范已同步。
