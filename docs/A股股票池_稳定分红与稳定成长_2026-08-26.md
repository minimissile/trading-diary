# A股股票池：稳定分红与稳定成长

> 数据日期：2026-08-26  
> 财务区间：2023—2025三个完整年度  
> 用途：长期观察池，不代表即时买入建议。

## 一、筛选口径

### 稳定分红池

- 汇总2023、2024、2025报告年度的税前现金股息；中期分红与年度分红按报告年度合并。
- 参考股息率 = 2025报告年度每股股息 ÷ 2026-08-25/26附近股价。
- 优先选择连续分红、股息不下降或仅小幅波动、经营现金流能够支持派息的公司。
- 一手成本按A股100股计算，不包含佣金。

稳定性等级：

- **A+**：三年股息未下降，当前参考股息率相对有吸引力。
- **A**：三年股息连续，当前收益率中等。
- **A-**：分红连续，但当前收益率偏低。
- **B+**：三年中存在一次小幅下降或波动，需要更高安全边际。

### 稳定成长池

- 硬性条件：2023→2024→2025营业收入和归母净利润均逐年增加。
- CAGR按三个年度、两个增长区间计算：`(2025年数值 ÷ 2023年数值)^(1/2) - 1`。
- 可成长性综合考虑竞争优势、行业空间、产品升级和海外扩张，不以题材热度代替业绩。

## 五、股票池维护规则

1. 每个季度更新收入、归母净利润、经营现金流和负债变化。
2. 若现金股息同比削减超过10%，降低分红稳定性评级。
3. 若连续两个年度收入或归母净利润下降，将公司移出成长池。
4. 若利润增长主要来自资产处置、公允价值或其他一次性收益，降低成长评级。
5. 实盘中单一行业不超过25%；银行只选1—2只，高速公路只选1只。
6. 进入股票池不等于可以买入，仍需结合估值、股息率和价格趋势确定买点。
